# SF 개념 사전

소설·애니메이션·만화·게임의 **우주 SF 세계**를, 작품을 가로지르는 **개념**으로 묶어 보는 사전입니다.
개념 하나(예: 「빛보다 빠른 이동」, 「숨는 우주」, 「남을 제 것으로 바꾸는 동화」)를 열면, 작품마다 그것을 무엇이라 부르고 어떻게 다루는지가 나온 해 순서로 나란히 보입니다.

- 개념 131개 · 작품 23편의 용어 1,656개 · 로어 조각 855개 · 찾아 둔 SF 세계 6,468곳 (2026-10-21)
- 찾아 둔 세계는 SF 전부를 모으는 목록입니다(영화·지구 위 이야기·SF 가 얇은 것도 표시를 달아 넣음). 용어·로어 조사는 그 가운데 우주와 관련된 세계와 사이버펑크만 합니다.
- 작품마다 세계를 이해하는 데 꼭 필요한 용어를 고르고, 작품이 이야기로 들려주는 **로어 조각**(불가사의·유물·사건 이야기 등)도 모으는 중입니다.
- 한 작품씩 천천히 늘려 갑니다. 지금은 우주와 관련된 세계만, 덜 알려졌지만 세계관이 탄탄한 쪽부터 조사합니다.

## 보는 법

`python scripts/build.py` 를 돌리면 `dist/index.html` 한 파일이 만들어집니다. 브라우저로 열면 됩니다(자료가 파일 안에 들어 있어 인터넷 연결이 필요 없습니다). 휴대폰 화면도 맞춥니다.

## 지키는 것

- **한글 표기는 정식 한국어판에서 확인합니다.** 번역 책, 게임 한국어판, 정식 자막·스트리밍 소개문. 기억으로 짓지 않습니다.
  - 정식판에서 직접 본 것은 `공식 · 원자료`, 정식판 표기라고 전하는 자료로 본 것은 `공식 · 2차 자료`.
  - 정식 표기가 없으면 국내 팬들이 쓰는 이름(나무위키 등)을 따르고 `우리 표기` 로 둡니다. 그것도 없으면 원어를 소리 나는 대로 적습니다.
- **남의 글을 옮기지 않습니다.** 설명과 로어 요약은 모두 이 레포에서 새로 쓴 글입니다. 작품 속 글(불가사의 글, 인물의 말, 사건 글)은 싣지 않고 무슨 이야기인지만 적습니다.
- 인물은 용어로 넣지 않습니다. 줄거리를 터뜨리는 설명은 `누설` 로 표시해 화면에서 접어 둡니다.
- `python scripts/check.py` 가 모든 항목을 점검합니다(빠진 칸, 없는 개념, 길이, 위아래 개념을 함께 단 것 등).

## 자료 틀

| 파일 | 내용 |
|---|---|
| `data/concepts.json` | 갈래와 개념 — 한 줄 정의, 설명, 위 개념, 비슷한 개념과 다른 점 |
| `data/terms/<작품>.json` | 작품 용어 — 한글 표기와 근거, 원어, 갈래, 이어지는 개념, 한 줄·설명, 누설 여부 |
| `data/lore/<작품>.json` | 로어 조각 — 이름, 어디서 나오나, 무슨 이야기인지(우리 말 요약), 이어지는 용어·개념 |
| `data/works.json` | 작품 — 기준으로 삼은 판, 쓴 정식 한국어판 |
| `data/candidates/` · `data/candidates_merged.json` | 찾아 둔 SF 세계 후보와 그 합본 |
| `data/space_filter.json` · `data/fame.json` | 세계마다 우주 관련인지, 얼마나 알려졌는지(조사 차례를 정할 때 씀) |
| `docs/` | 조사 지침과 기록 |

## 알려 둘 것

작품 이름·용어·세계관의 권리는 각 작품의 권리자에게 있습니다. 이 레포는 어느 권리자와도 관계없는 개인 정리입니다.
