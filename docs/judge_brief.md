# 세계 판정 맡김 — 우주 · 알려진 정도 · 사이버펑크

SF 개념 사전(`C:\Users\jin0x\dev\sandbox\sf-lexicon`)의 '찾은 세계' 가운데 판정이 빈 곳에 세 가지를 매긴다.
덩이는 `python scripts/judge.py make <작업 폴더>` 가 만든 `in_NN.tsv`(첫 줄은 칸 이름). 맡은 덩이마다 같은 폴더에 `out_NN.txt` 를 쓴다(NN 은 같은 번호). 다 쓰면 `python scripts/judge.py apply <작업 폴더>` 가 검사해 넣는다(판정하는 에이전트는 apply 를 돌리지 않는다).

처음 매긴 때: 2026-10-21, 3,126곳(덩이 여덟, 에이전트 넷).

## 쓰는 꼴

한 줄에 세계 하나, 칸은 탭:

```
id<TAB>S<TAB>F<TAB>C<TAB>까닭
```

- `S` 우주: `Y` 예 · `N` 아니오 · `B` 경계
  - 예: 우주가 세계의 바탕 — 사람(또는 이야기의 중심 쪽)이 우주로 나가거나, 우주·다른 행성·우주 거주지·우주선이 주 무대이거나, 별 사이 문명·전쟁·교류가 큰 축(우주를 건너 온 행성도 예).
  - 아니오: 지구(또는 행성 하나) 위에서만 벌어지고 우주로 나가지 않음 — 종말 뒤 지구, 사이버펑크 도시, 유전자·로봇·인공지능·괴수·가상 현실·시간 여행만 있는 세계, 우주 개념 없이 낯선 행성만 있는 세계.
  - 경계: 둘 사이 — 외계 존재가 지구에 오지만 사람은 못 나감, 시리즈 일부 작품에만 우주 대목, 우주가 배경 설정에만 살짝. ★SF 인지 자체가 애매한 것(대체역사 빙의·환생물, 시간 여행 로맨스, 초자연 위주)도 우주가 없으면 `N`.
  - 마지막 칸 '이미 한 우주 판정'이 차 있으면 `S` 는 그 값을 Y/N/B 로 그대로 옮긴다(다시 판정하지 않는다).
- `F` 알려진 정도(1~5):
  - 5 대중 대작: SF 를 안 보는 사람도 이름을 아는 것(큰 흥행 영화가 붙은 프랜차이즈, 세계적 장수 인기작, 국내에서도 누구나 아는 작품)
  - 4 넓게 알려짐: 장르 팬이면 거의 다 알고 일반에도 꽤 알려진 것
  - 3 장르 안에서 이름난 것: SF 팬 사이에선 유명하지만 대중엔 덜 알려진 것
  - 2 마이너하지만 탄탄한 것: 아는 사람만 아는 쪽, 그러나 시리즈가 이어졌거나 상을 받았거나 세계관이 두꺼운 것
  - 1 아주 마이너: 자료가 아주 적어 세계관을 정리하기 어려울 만큼 덜 알려진 것
  - 국내와 해외 인지도가 크게 다르면 둘을 반쯤 섞어 매긴다. 모르는 작품은 '알려진 근거' 칸을 보고 1~2 로.
- `C` 사이버펑크: `C` 이면 사이버펑크 세계, 아니면 `-`.
  - `C`: 높은 기술·낮은 삶 — 몸에 기계를 심거나 뇌를 망에 잇고, 거대 기업·감시가 도시를 쥐고, 해커·용병·뒷골목이 이야기의 중심인 세계(사이버펑크·포스트사이버펑크·테크 누아르, 사이버스페이스·전뇌가 중심인 세계 포함).
  - `-`: 로봇·인공지능·유전자 조작·가상 현실이 나와도 위 분위기가 아니면(괴수물, 슈퍼히어로·변신 히어로물, 우주 활극, 밝은 미래, 종말 뒤 황무지만 있는 것) `-`. 바이오펑크·스팀펑크·디젤펑크·솔라펑크는 `-`.
- 까닭: 우주 판정의 까닭을 30자 안 우리말로(예: `달 기지가 주 무대`, `지구 위 괴수 습격만`). 탭·줄바꿈 금지.

## 지킬 것

- 입력의 모든 줄을 빠짐없이, 같은 차례로 쓴다. 다 쓴 뒤 줄 수와 id 가 입력과 같은지 짧은 파이썬으로 확인한다(`PYTHONUTF8=1`).
- 아는 것과 주어진 '세계 한 줄'로 판단한다. 웹 검색·웹 페이지 받기는 하지 않는다(필요 없다).
- 레포 파일은 고치지 않는다. 커밋하지 않는다. 작업 폴더의 `out_NN.txt` 만 쓴다.
- 우리말로, 영어 낱말을 섞지 않는다(작품 이름은 예외).
- 끝나면 덩이마다 Y/N/B 수, F 1~5 수, C 수를 한 줄씩 보고한다.
