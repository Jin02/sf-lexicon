# 세계 더 찾기 — 훑을 곳

진님(2026-10-20): **"지구상 이제까지 만들어진 sf 모든 작품을 찾아서 정리한다", "이게 이 세션의 할일이야"**.
찾은 세계 목록은 SF 전부다(영화·우주 아닌 것·슈퍼히어로도 — 슈퍼히어로·판타지 곁들인 것은 `borderline`). 조사 차례의 기준(우주·영화·슈퍼히어로·마이너)은 목록과 따로다.

한 줄 = 세계 더 찾기 하나. 위에서부터 아직 안 한(`[ ]`) 줄을 맡는다. 맡으면 `[~]` 와 맡은 곳(세션·예약)을 적고, 끝나면 `[x]` 와 날짜·새로 찾은 수.

## 더 찾기 절 (survey_brief.md 에 더해)

- 이미 있는 세계(`data/candidates_merged.json` 의 `worlds` — id·orig·ko·series·by)는 넣지 않는다. 넣기 전에 원제·한국어 제목·지은이로 맞춰 본다(파이썬으로 읽어 비교).
- 만들 파일: `data/candidates/sweep_<번호>_<짧은 이름>.json` — `{"group": "sweep_<번호>_<짧은 이름>", "candidates": [...]}`.
- survey_brief.md 의 '많이 훑을 때' 를 따른다 — 한국어판은 한 건씩 검색하지 않는다.
- 나무위키 문서는 `https://namu.wiki/w/<문서 이름>`(분류 문서도 `/w/분류:…`, robots.txt 가 `/w/` 허용). 영어·일본어·중국어 위키백과 목록 문서도 쓴다 — ★위키백과는 `/wiki/<문서>`(원문이 필요하면 `/wiki/<문서>?action=raw`)만 쓴다. `/w/index.php` 는 robots.txt 가 막는다(사이버펑크 찾기 때 8쪽을 그렇게 받았다). 다른 곳은 robots.txt 를 따로 먼저 본다.
- 군대·나라가 만든 강화 병사가 나오는 전쟁 SF(헤일로·워해머 같은 것)는 슈퍼히어로가 아니다(borderline 아님).
- 한 줄이 너무 크면(목록이 수천 곳) 한 차례에 할 만큼 하고 어디까지 했는지 적어 남긴다.
